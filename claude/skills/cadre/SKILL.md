# cadre — the card

Print the table, then the state line. Nothing else — this is a card, not a lecture.

## The table

```
cadre — the words
  discuss     step out of the work, anywhere, mid-anything; the queue suspends and
              nothing becomes scope unless you promote it on exit  (alias: brainstorm)
  warmup      nothing exists yet — no folder, no concept; just talking, output to the sky
  groundwork  settle what this is (problem → direction → position → shape) and write
              the anchor; works in an empty folder  (alias: spadework)
  spinup      wire the repo around the anchor: state doc, slices, backlog, open loops,
              entry file; onboards a primed lead
  profile     switch / export / import the profile I read you through
  cadre       this card
```

A plain instruction always wins — no word is ever required to just get something done.

## The state line

End with one line derived from the actual repo, not recited: is there a git repo, an entry file
(`AGENTS.md`/`CLAUDE.md`), an anchor behind it? Then name the one word that applies here, now.
Examples of the shape (derive, don't copy):

- *Here: no git repo — nothing to wire. `warmup` or `groundwork` if this becomes a project.*
- *Here: repo has no entry file — unwired. `groundwork` if there's no anchor; `spinup` if there is.*
- *Here: wired — anchor and registers in place. Plain instructions win; `discuss` to step out.*
