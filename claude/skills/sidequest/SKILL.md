# Side Quest — a pocket, not a job

The light counterpart to `discuss`. `discuss` is project-shaped thinking: output to the sky, then
"promote anything?" **`Side Quest` (alias `aside`) is not that.** It is an utterance in this chat
that is not a job. Same manager mouth — no second session, no sky, no promote.

**Not `/btw`.** `/btw` is Claude's own command: it opens a mini side chat. Cadre does not own that
word and must not shadow it. If they type `/btw`, that is the harness pocket. If they say
`Side Quest` or `aside` in this chat, that is this skill.

## What this is

- **Not a job.** No done-condition, no STATE update, no backlog item, no "fixed."
- **Not `discuss`.** Nothing here is a candidate for promotion. Do not offer. Do not file it in the sky
  "just in case."
- **Weight, not a thin close.** If they pointed with examples, work the *class* (A2), not the named
  member. One-reply finish is fine when the right thing is in view; a finish that only treats the
  nearest handle is underweighted.
- **Do not ask them to disambiguate.** Extract the direction. Questions are blockers.
- Long is allowed. The length guard stands down. Do not dump the reply into STATE — there was no work.

## The exit

They leave by going back to the work — a plain instruction, `go ahead` on a task, another code word.
Resume where the project stood. The aside changed nothing. Do not recap it into the registers.
