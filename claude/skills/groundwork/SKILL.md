# groundwork — settle the field, write the anchor

The front half of the pair: **groundwork → anchor exists → spinup wires the registers around it.**
Mode is `mapping` throughout. This session's deliverable is the **anchor** — nothing else. No backlog,
no STATE doc, no entry file; those are spinup's.

## Steps — the outer rings, right-sized

1. **R0 — Problem.** Preserve the human's own words **verbatim, permanently** — the first framing can
   never be re-derived once paraphrased. Extract what was implied (deliverable, standard, audience,
   constraint) and say the read back in the same breath as starting.
2. **R1 — Read.** What this really is. Research if it needs research: who already ships this, what the
   territory looks like. Findings in one note.
3. **R2 — Direction.** Options + a recommendation. Theirs to pick, on my options.
4. **R3 — Position.** Why this, for whom, what it beats. One paragraph.
5. **R4 — Shape.** The whole of it: in · later · **never**. Counts and costs, not a wishlist.
6. **Write the anchor** — the whole field: what this is for, what is always true of it, where it goes.
   Deliberately NOT item-indexed. This session writes it; it is never spinup's output.
7. **Hand off:** "anchor is written — say `spinup` when you want the project wired."

## Right-sizing

- A small tool gets a one-page anchor and rings settled in one conversation. A product gets more. Never
  impose the full arc on a light job.
- **R5 (picture) is not groundwork.** It's on-trigger, later, per ringwork — don't design screens here.
- Rings the human has already settled: adopt, don't re-derive. Arriving with a concept means entering
  at R2, not re-interviewing them about R0.

## Existing project, no anchor

Reverse-derive: the built thing embodies R0–R4, so read the repo and existing docs, draft the anchor
from what is *actually true*, and have the human correct it. Adopt existing docs as sources — never
restate them into a second version of themselves.

## Guardrails

- **An anchor written by the same pass that builds a backlog is just the backlog with a preface.**
  Groundwork never produces queue items; findings that look like tasks go to the sky or wait for spinup.
- Each ring's output is theirs to confirm — options and recommendations, not decisions made for them.
- If the human arrives mid-warmup with a crystallized idea, start from the sky notes; don't make them
  repeat what they already said there.
